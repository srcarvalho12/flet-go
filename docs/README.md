# flet-go documentation

flet-go is in an early stage: the API may still change. If something is missing or
unclear, please [open an issue](https://github.com/srcarvalho12/flet-go/issues).

1. [Getting started](getting-started.md): install, first app, desktop and web.
2. [Controls, events and methods](controls.md): how Flet controls map to Go.
3. [Pages, dialogs, services and state](page.md): the page, views, theme,
   dialogs, services, `page.Run` and per-session values.
4. [Routing](routing.md): pages in separate files, layouts, middleware and
   stacked screens.
5. [Web apps](web.md): serving, base paths, uploads, assets and sessions.
6. [Desktop apps](desktop.md): the desktop window and its client.
7. [Architecture](architecture.md): protocol, diffing and code generation.

The [examples](../examples) folder has a runnable program for each topic.
